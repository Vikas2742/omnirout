> Toggle runtime yang mengubah perilaku OmniRoute **tanpa deployment ulang**.
> Setiap flag yang tercantum di sini didefinisikan dalam
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — satu-satunya sumber kebenaran. Dasbor dan REST API sama-sama membaca dari
> file tersebut, sehingga tabel di bawah dibuat agar sesuai dengannya secara 1:1.

---

## Apa Itu Feature Flag

Feature flag adalah toggle bernama (boolean atau enum) yang nilainya dapat diubah
saat runtime dan disimpan secara persisten dalam database, tanpa memerlukan deployment
ulang proses. Setiap flag dijelaskan oleh `FeatureFlagDefinition` dengan `key`, `label`,
`description`, `category`, `defaultValue`, `type`, dan petunjuk `requiresRestart`.

### Urutan Resolusi

**Nilai efektif** suatu flag ditentukan oleh
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) dengan urutan
prioritas berikut (yang tertinggi berlaku):

1. **Override DB** — nilai yang disimpan dalam tabel `key_value` di bawah namespace
   `feature_flags` (ditetapkan melalui dasbor atau REST API).
2. **Variabel lingkungan** — `process.env[<KEY>]`, jika ditetapkan dan tidak kosong.
3. **Default definisi** — `defaultValue` dari `featureFlagDefinitions.ts`.

Flag boolean dianggap **diaktifkan** ketika nilai efektifnya adalah `"true"`,
`"1"`, atau `"yes"` (lihat `isFeatureFlagEnabled()`).

> [!NOTE]
> Sebagian besar flag juga memiliki variabel lingkungan yang sesuai dengan **nama yang sama**
> dan didokumentasikan dalam [`ENVIRONMENT.md`](./ENVIRONMENT.md). Override DB untuk flag
> lebih diprioritaskan daripada variabel lingkungan tersebut. Flag dengan
> `requiresRestart: true` langsung disimpan secara persisten, tetapi hanya dibaca ulang saat
> proses dimulai — mengubahnya akan menampilkan banner **"Mulai Ulang Server"** di dasbor.

### Kebijakan (7)

| Kunci                           | Tipe    | Default       | Deskripsi                                                                                                                                                                                                                                                                                                                              |
| ------------------------------- | ------- | ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `UNPRICED_USAGE_BUDGET_POLICY`  | enum    | `fail_closed` | Cara batas USD harian/mingguan per kunci memperlakukan penggunaan yang penyedia/modelnya tidak memiliki baris harga. `fail_closed` (default) menandai periode sebagai terlampaui (#12341); `count_as_zero` menghitungnya sebagai $0 dan tetap menerapkan batas pengeluaran yang memiliki harga. | `TOOL_POLICY_MODE`              | enum    | `disabled`    | Mode penerapan kebijakan penggunaan alat. | `RATE_LIMIT_AUTO_ENABLE`        | boolean | `false`       | Paksa pengaktifan/penonaktifan otomatis mekanisme pengaman batas laju melalui variabel lingkungan. Runtime hanya membaca variabel lingkungan: jika tidak disetel, pengaturan dasbor yang diikuti (aktif secara default), bukan nilai default katalog ini.                                                                              |
| `DISABLE_CONTEXT_WINDOW_CHECKS` | boolean | `false`       | Lewati pemeriksaan lokal jendela konteks / token masukan maksimum OmniRoute untuk permintaan langsung ke satu model. | `CAPABILITY_FILTER_ENABLED`     | boolean | `false`       | Tolak permintaan sebelum dikirim jika model tujuan tidak memiliki kapabilitas yang diperlukan (visi, alat, keluaran terstruktur, jendela konteks). Melindungi permintaan langsung ke satu penyedia yang melewati filter kompatibilitas lapisan kombinasi.                                                                              |
| `USAGE_LIMIT_IGNORE_UNPRICED`   | boolean | `false`       | Hitung penggunaan model yang tidak memiliki harga sebagai $0 dalam kuota penggunaan USD per kunci, alih-alih menganggap kuota telah terlampaui. Nonaktif secara default: model tanpa harga atau alias perutean dapat menyembunyikan pengeluaran nyata, sehingga kuota memblokir penggunaan jika harga tidak tersedia.                  |
| `RADAR_ENABLED`                 | boolean | `false`       | Aktifkan modul OmniRoute Radar (layar umpan katalog dan sinkronisasi). Nonaktif secara default; pengaktifan hanya membuka akses ke UI — sinkronisasi data tetap memerlukan persetujuan terpisah.                                                                                                                                       |

Ketika `UNPRICED_USAGE_BUDGET_POLICY` dikonfigurasi secara eksplisit (pengaturan pengganti di DB diprioritaskan sebelum variabel lingkungan),
kebijakan ini lebih diutamakan daripada `USAGE_LIMIT_IGNORE_UNPRICED`. Jika tidak ada nilai enum eksplisit,
opsi penonaktifan boolean dari upstream memilih `count_as_zero`; jika tidak, nilai defaultnya adalah `fail_closed`.
Nilai enum yang tidak valid dan penyimpanan flag fitur yang tidak dapat dibaca akan memblokir akses secara default. Kedua opsi penonaktifan tersebut tidak melonggarkan
pengeluaran yang memiliki harga maupun kegagalan pencarian harga. Penegakan kebijakan dan laporan administrator menentukan

## Mengubah Flag

### Dasbor

Navigasikan ke **Dasbor → Pengaturan → Feature Flags**
(`/dashboard/settings/feature-flags`). Grid
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
mendukung:

- **Pencarian** berdasarkan kunci atau deskripsi, dan **filter** berdasarkan kategori (ditambah tampilan sintetis **Membutuhkan Restart**).
- Sebuah **tombol sakelar** untuk flag boolean dan **dropdown** untuk flag enum
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- Sebuah **badge sumber** per flag — `DB`, `ENV`, atau `DEF` — yang menunjukkan dari mana nilai efektif berasal.
- Tombol **Reset** (ditampilkan hanya untuk flag bersumber `DB`) untuk menghapus override, dan tombol **Reset Semua Override** di bagian bawah.
- Sebuah banner **Restart Server** ketika flag `requiresRestart` diubah.

### API REST

Semua operasi melalui satu rute:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
Setiap metode memerlukan sesi dasbor yang terautentikasi (`401` jika tidak).

#### `GET /api/settings/feature-flags`

Mengembalikan setiap flag dengan nilai efektifnya, sumber, dan ringkasan.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... semua 77 flag
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Mengatur atau menghapus satu override. Body: `{ key: string; value?: string }`.
Menghilangkan `value` akan menghapus override (mengembalikan ke env / default).

```bash
# Atur override DB
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Hapus override (tanpa "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Respons menggemakan `effectiveValue`/`source` yang baru, `previousValue`/
`previousSource` sebelumnya, dan `requiresRestart`. Kunci yang tidak dikenal dan nilai enum di luar jangkauan akan ditolak dengan `400`.

#### `DELETE /api/settings/feature-flags`

Menghapus **semua** override DB sekaligus, mengembalikan setiap flag ke nilai env / default-nya. Mengembalikan `{ cleared: <count>, message: "..." }`.

> [!NOTE]
> Flag dengan `requiresRestart: true` hanya akan berlaku setelah proses dimuat ulang.
> Alur restart dasbor memanggil `POST /api/restart` dan kemudian melakukan polling
> `GET /api/health/ping` hingga server kembali aktif.

## Fallback Anggaran Darurat

`OMNIROUTE_EMERGENCY_FALLBACK` (kategori `runtime`, default `true`) mengontrol
jalur fallback gratis darurat di
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Saat diaktifkan, permintaan yang kehabisan anggaran akan dialihkan ke
penyedia/model fallback gratis alih-alih langsung mengalami kegagalan. Atur ke
`false` (atau `0`) — melalui toggle dasbor, override DB, atau variabel lingkungan
`OMNIROUTE_EMERGENCY_FALLBACK` — untuk menonaktifkan perilaku ini dan membiarkan
permintaan yang kehabisan anggaran mengalami kegagalan. (Ditampilkan sebagai
toggle dasbor dalam PR #3741 / #3752.)

Respons yang dilayani oleh fallback ini membawa
`X-OmniRoute-Emergency-Fallback: from=<provider/model>; to=<provider/model>`,
sehingga klien dapat mengetahui bahwa permintaan telah dialihkan tanpa perlu
membandingkan `X-OmniRoute-Provider` dengan permintaannya. Header ini tidak ada
pada semua respons lainnya.
