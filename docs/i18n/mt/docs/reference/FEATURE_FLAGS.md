## X'inhuma l-Feature Flags

Feature flag huwa toggle imsemmi (boolean jew enum) li l-valur tiegħu jista' jinbidel waqt l-eżekuzzjoni u jiġi ppersistut fid-database, mingħajr ma jkun meħtieġ redeploy tal-proċess. Kull flag huwa deskritt minn `FeatureFlagDefinition` b' `key`, `label`, `description`, `category`, `defaultValue`, `type`, u `requiresRestart` hint.

### Ordni ta' Riżoluzzjoni

Il-**valur effettiv** ta' flag jiġi riżolt minn
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) b'din il-preċedenza (l-ogħla tirbaħ):

1.  **DB override** — valur maħżun fit-tabella `key_value` taħt in-namespace `feature_flags` (issettjat permezz tad-dashboard jew il-REST API).
2.  **Varjabbli tal-ambjent** — `process.env[<KEY>]`, jekk issettjat u mhux vojt.
3.  **Default tad-definizzjoni** — il-`defaultValue` minn `featureFlagDefinitions.ts`.

Flag boolean huwa kkunsidrat **attivat** meta l-valur effettiv tiegħu jkun `"true"`, `"1"`, jew `"yes"` (ara `isFeatureFlagEnabled()`).

> [!NOTE]
> Ħafna flags għandhom ukoll varjabbli tal-ambjent korrispondenti tal-**istess isem**
> dokumentata f'[`ENVIRONMENT.md`](./ENVIRONMENT.md). L-override tad-DB tal-flag
> tieħu preċedenza fuq dik il-varjabbli tal-ambjent. Flag b'
> `requiresRestart: true` jiġi ppersistut immedjatament iżda jerġa' jinqara biss mal-bidu tal-proċess
> — it-toggle tiegħu juri banner ta' **"Restart Server"** fid-dashboard.

## Qlib tal-Flags

### Dashboard

Innaviga lejn **Dashboard → Settings → Feature Flags**
(`/dashboard/settings/feature-flags`). Il-grid
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
tappoġġja:

- **Fittex** skont iċ-ċavetta jew id-deskrizzjoni, u **ffiltra** skont il-kategorija (flimkien ma' veduta sintetika ta' **Jeħtieġ Restart**).
- Toggle għal flags booleani u **dropdown** għal flags enum
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- Badge tas-sors għal kull flag — `DB`, `ENV`, jew `DEF` — li turi minn fejn ġie l-valur effettiv.
- Buttuna **Reset** (murija biss għal flags b'sors `DB`) biex tneħħi l-override, u buttuna **Reset All Overrides** fil-qiegħ.
- Banner ta' **Restart Server** meta flag `requiresRestart` tinbidel.

### REST API

L-operazzjonijiet kollha jgħaddu minn rotta waħda:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
Kull metodu jeħtieġ sessjoni awtentikata tad-dashboard (401 inkella).

#### `GET /api/settings/feature-flags`

Tirritorna kull flag bil-valur effettiv, is-sors, u sommarju tagħha.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... it-77 flag kollha
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Issettja jew neħħi override waħda. Korp: `{ key: string; value?: string }`.
Jekk tħalli `value` barra, tneħħi l-override (tirrestawra l-env / default).

```bash
# Issettja override tad-DB
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Neħħi l-override (mingħajr "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Ir-rispons jirrifletti l-`effectiveValue`/`source` il-ġdid, il-`previousValue`/
`previousSource` preċedenti, u `requiresRestart`. Ċwievet mhux magħrufa u valuri enum barra mill-firxa jiġu rrifjutati b'`400`.

#### `DELETE /api/settings/feature-flags`

Tnaddaf **l-overrides kollha** tad-DB f'daqqa, u tirrestawra kull flag għall-valur env / default tagħha. Tirritorna `{ cleared: <count>, message: "..." }`.

> [!NOTE]
> Flags b'`requiresRestart: true` jidħlu fis-seħħ biss wara li l-proċess jerġa' jitgħabba. Il-fluss ta' restart tad-dashboard isejjaħ `POST /api/restart` u mbagħad jivverifika `GET /api/health/ping` sakemm is-server jerġa' jkun attiv.

## Alternattiva ta' Emerġenza għall-Baġit

`OMNIROUTE_EMERGENCY_FALLBACK` (kategorija `runtime`, valur predefinit `true`) jikkontrolla l-mogħdija alternattiva bla ħlas ta' emerġenza f'
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Meta tkun attivata, it-talbiet li jeżawrixxu l-baġit tagħhom jiġu diretti lejn
fornitur/mudell alternattiv bla ħlas minflok ma jfallu għalkollox. Issettjaha għal `false` (jew `0`) — permezz tal-
buttuna fid-dashboard, override fid-DB, jew il-varjabbli ambjentali
`OMNIROUTE_EMERGENCY_FALLBACK` — biex tiddiżattiva din l-imġiba u tħalli t-talbiet
li jkunu eżawrew il-baġit ifallu. (Murija bħala buttuna fid-dashboard fil-PRs #3741 / #3752.)

Risposta pprovduta minn din l-alternattiva jkollha
`X-OmniRoute-Emergency-Fallback: from=<provider/model>; to=<provider/model>`, sabiex
klijent ikun jista' jagħraf li ġiet diretta mill-ġdid mingħajr ma jqabbel `X-OmniRoute-Provider` mat-
talba tiegħu. L-header ma jkun preżenti fl-ebda risposta oħra.
