## Comhlánuithe Comhrá

```bash
POST /v1/chat/completions
Authorization: Bearer your-api-key
Content-Type: application/json

{
  "model": "cc/claude-opus-4-6",
  "messages": [
    {"role": "user", "content": "Write a function to..."}
  ],
  "stream": true
}
```

| `X-OmniRoute-Progress`   | Iarratas | Socraigh mar `true` le haghaidh teagmhais dul chun cinn                                                                                                                                                                                                                                   |

| `X-OmniRoute-Cache`      | Freagra  | `HIT` nó `MISS` (neamhshruthaithe)                                                                                                                                                                                                                                                        |
| `X-OmniRoute-Idempotent` | Freagra  | `true` má dí-dhúbláladh é                                                                                                                                                                                                                                                                 |

#### Pionnáil cuntais in aghaidh an iarratais

Nuair a bhíonn roinnt nasc (cuntas nó eochair) ag soláthraí, roghnaíonn OmniRoute ceann amháin de ghnáth
trína straitéis roghnaithe cuntais. Ina ionad sin, is féidir le hiarratas nasc sonrach amháin a phionnáil
leis an gceannteideal `x-omniroute-connection`:

```bash
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer <your OmniRoute API key>" \
  -H "Content-Type: application/json" \
  -H "x-omniroute-connection: <connection id>" \
  -d '{"model": "codex/gpt-5.5", "messages": [{"role": "user", "content": "hi"}]}'
```

- **Cá bhfaighidh tú an t-aitheantas.** Oscail leathanach an tsoláthraí sa deais
  (**Deais → Soláthraithe → <provider>**) agus cliceáil sliseanna aitheantais `xxxxxxxx…` ar ró naisc
  — cóipeálann sé aitheantas iomlán an naisc.
- **Cé na hiarratais a thugann éifeacht dó.** Iarratais aon-samhla (`provider/model`) ar
  `/v1/chat/completions`, `/v1/messages` agus `/v1/responses`. Déanann teaglamaí neamhaird den cheannteideal: pionnáil
  cuntas do gach céim teaglama trí nasc na céime féin ina ionad sin.
- **Tá an phionnáil docht, ní rogha thosaíochta í.** Úsáidtear an nasc pionnáilte go heisiach. Má
  theipeann rud éigin laistigh den iarratas, taifeadtar tréimhse fuaraithe an chuntais ach **ní** aistrítear chuig
  cuntas eile de chuid an tsoláthraí chéanna.
- **Scaoileann fuarú agus cuóta an phionnáil.** Fad atá an nasc pionnáilte ag fuarú,
  a chuóta ídithe nó é bactha ag polasaí cuóta, téann iarratais ina dhiaidh sin ar ais chuig naisc eile an tsoláthraí,
  díreach mar a dhéantar le trácht neamhphionnáilte.
- **Teipeann ar aitheantais anaithnide nó dhíchumasaithe.** Má tá aitheantas nach bhfuil i linn ghníomhach an tsoláthraí (scriosta,
  díghníomhachtaithe, nó a bhaineann le soláthraí eile), ní bhíonn aon chuntas incháilithe fágtha, agus mar sin teipeann ar an iarratas
  seachas é a ródú go ciúin áit éigin eile.

Seolann Claude Code ceanntásca saincheaptha trí `ANTHROPIC_CUSTOM_HEADERS`. Cuir sa bhloc `env` é
in `~/.claude/settings.json`, nó in `.claude/settings.json` ar leibhéal an tionscadail chun cuntas difriúil a phionnáil
do gach tionscadal:

```jsonc
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://<your OmniRoute>:20128",
    "ANTHROPIC_AUTH_TOKEN": "<your OmniRoute API key>",
    "ANTHROPIC_CUSTOM_HEADERS": "x-omniroute-connection: <connection id>",
  },
}
```

Foinse: `src/sse/handlers/chat.ts` (léamh an cheanntáisc), `src/sse/services/auth.ts` agus
`src/sse/services/sessionAffinityPin.ts` (scaoileadh na pionnála agus an tseiceáil nach bhfuil sé sa linn).

> **Ceanntásca teiliméadrachta costais:** iompraíonn freagraí rathúla neamhshruthaithe tacar teiliméadrachta costais `X-OmniRoute-*` freisin — `X-OmniRoute-Response-Cost` (USD, 10 n-ionad dheachúlacha socraithe; `0.0000000000` do chinn saor in aisce/neamhphraghsáilte), `X-OmniRoute-Tokens-In` / `X-OmniRoute-Tokens-Out`, `X-OmniRoute-Model`, `X-OmniRoute-Provider`, `X-OmniRoute-Latency-Ms`, `X-OmniRoute-Cache-Hit`, agus `X-OmniRoute-Fallback-Attempts` (nuair atá sé > 0 amháin), chomh maith le `X-OmniRoute-Request-Id` agus `X-OmniRoute-Version`. Astaítear iad seo ag comhlánuithe comhrá, `/v1/responses`, `/v1/messages`, **agus na críochphointí meán** — `/v1/embeddings`, `/v1/images/generations`, `/v1/audio/speech`, `/v1/audio/transcriptions`, `/v1/rerank`, `/v1/videos/generations`, `/v1/music/generations`, agus `/v1/moderations` (costas `0` i gcónaí). Ríomhtar costas meán de réir na módúlachta (in aghaidh na híomhá, in aghaidh an tsoicind, in aghaidh an charachtair, in aghaidh an aonaid chuardaigh) nuair atá praghsáil ar fáil; murach sin, is é `0` é (teip-oscailte).

> **Séimeantaic costais amas taisce:** i gcás AMAIS ar thaisce shéimeantach (`X-OmniRoute-Cache-Hit: true`) ní dhéantar aon ghlao réamhtheachtach, mar sin is é `0.0000000000` luach `X-OmniRoute-Response-Cost` (an costas **incriminteach** a bhaineann leis an amas a sheirbheáil). Tuairiscítear an bunchostas/an costas a bheadh ann ar leithligh in `X-OmniRoute-Cost-Saved`. Ba cheart do thomhaltóirí billeála suim `X-OmniRoute-Response-Cost` a ríomh (ní chosnaíonn amais tada); is féidir le hanailísíocht taisce `X-OmniRoute-Cost-Saved` a chomhiomlánú.

## Léasanna Eisiacha Seisiúin Bhainistithe

Is conradh ródaithe roghnach, neodrach ó thaobh cliaint de é léasú eisiach seisiúin bhainistithe: bíonn nasc incháilithe OmniRoute amháin i seilbh úinéara ghníomhaigh amháin. Ní thugann sé samhail ar léas, ní éilíonn sé OAuth, ní shainaithníonn sé cliant ar leith, agus ní éilíonn sé soláthraí ar leith.

Ní mór don eochair API fíordheimhnithe raon feidhme `lease:exclusive` agus liosta sainráite neamhfholamh `allowedConnections` a bheith aici. Forfheidhmíonn teorainn athraithe an bhunachair sonraí an dá réimse le chéile nuair a chruthaítear eochair agus nuair a dhéantar nuashonruithe páirteacha.

```http
POST /api/v1/session-leases
Authorization: Bearer <managed-api-key>
Content-Type: application/json
X-OmniRoute-Lease-Owner: vlo_<43-base64url-characters>

{"action":"acquire","model":"glm/glm-4.6"}
```

Nochtann freagraí rathúla fála, athnuachana agus scaoilte stampaí ama, `state`, agus an `generation` deimhneach beacht, ach ní nochtann siad an nasc roghnaithe ná na dintiúir riamh. Soláthraíonn athnuachan agus scaoileadh an ghlúin sa chorp JSON:

```json
{ "action": "renew", "generation": 1 }
```

```json
{ "action": "release", "generation": 1, "reason": "OWNER_EXIT" }
```

Is féidir le húinéir léasa ghníomhaigh meiteashonraí taispeána atá sábháilte ó thaobh príobháideachais de a iarraidh go sainráite dá cheangal reatha:

```json
{ "action": "status", "generation": 1 }
```

```json
{
  "state": "ACTIVE",
  "generation": 1,
  "acquiredAt": "2026-08-28T12:00:00.000Z",
  "renewedAt": "2026-08-28T12:00:30.000Z",
  "expiresAt": "2026-08-28T12:02:30.000Z",
  "connection": {
    "displayName": "Primary Codex",
    "provider": "codex"
  }
}
```

Déantar an gníomh roghnach stádais seo a fhálú leis an úinéir teimhneach, an eochair API bhainistithe fhíordheimhnithe, agus an ghlúin ghníomhach bheacht in idirbheart bunachair sonraí amháin. Níl in `displayName` ach ainm cumraithe an naisc agus é bearrtha; is `null` é nuair nach bhfuil aon ainm cumraithe sábháilte ann. Ní chuireann OmniRoute seoladh ríomhphoist ná aitheantas cuntais ginte ina ionad riamh. Is lipéad taispeána neamhíogair é luach an tsoláthraí agus ní aitheantóir ginte soláthraí chomhoiriúnaigh é riamh. Fágtar dintiúir, comharthaí, fianáin, aitheantóirí amh naisc nó eochrach API, haiseanna úinéara, rúin fálaithe, agus sonraí inmheánacha ródaithe ar lár.

Tugann cuardaigh leis an eochair mhícheart, an t-úinéir mícheart, glúin as dáta, nó cuardaigh atá ar iarraidh, imithe in éag, scaoilte nó neamhbhailíochtaithe, an earráid chéanna `409 LEASE_FENCE_STALE` ar ais gan meiteashonraí naisc. Níl aon cheangal gníomhach le hiniúchadh ag cliant a fuair an freagra feithimh ar acmhainn. Nuair a aistríonn an ródú léas gníomhach, fanann an ghlúin chéanna bailí agus tugann an stádas an ceangal nua ar ais go hadamhach, seachas an seancheangal riamh. Ní athraítear cliaint atá ann cheana toisc go gcoinníonn freagraí fála, athnuachana, scaoilte agus feithimh na cruthanna a bhí acu roimhe seo.

Ní athraíonn an conradh freastalaí seo `/status` caighdeánach OpenAI Codex. Faoi láthair, tuairiscíonn Codex caighdeánach a sholáthraí samhla agus a staid ionsuite fíordheimhnithe/cuntais, ach ní rindreálann sé meiteashonraí saincheaptha treallacha cuntais soláthraí; ní mór do chomhtháthú cliaint amach anseo an gníomh seo a ghlaoch agus cinneadh a dhéanamh conas `connection.displayName` a thaispeáint.

Ansin soláthraíonn gach iarratas tátail bhainistithe an dá cheanntásc rialaithe:

```http
X-OmniRoute-Lease-Owner: vlo_<43-base64url-characters>
X-OmniRoute-Lease-Generation: 1
```

Déantar an t-úinéir beacht, an ghlúin, an nasc gníomhach, agus an eochair API fhíordheimhnithe a fhálú díreach roimh gach iarracht tacaithe réamhtheachtach. Teipeann ar athsheinm an úinéara agus na glúine le heochair eile fiú nuair a cheadaíonn an eochair sin an nasc céanna. Ní dhéantar úinéirí amha a bhuanú, a logáil, a choinneáil i léargas an iarratais, ná a chur ar aghaidh réamhtheachtach.

Tugann coimhlint shealadach HTTP `429` ar ais le `Retry-After` agus:

```json
{
  "state": "WAITING_FOR_CAPACITY",
  "error": { "type": "lease_error", "code": "LEASE_CAPACITY_UNAVAILABLE" },
  "reason": "NO_FREE_ELIGIBLE_CONNECTION",
  "retryAfter": 30
}
```

Ní chiallaíonn an freagra seo ach nach raibh an gnáth-thacar incháilithe folamh agus go raibh gach iarrthóir saor i seilbh léasa ghníomhaigh eachtraigh. Coinníonn samhlacha/soláthraithe nach dtacaítear leo, neamhréir beartais, tréimhse shuaimhnithe, cuóta, sláinte, agus gnáth-theipeanna incháilitheachta eile na freagraí OmniRoute atá acu cheana.

### `x-omniroute-compression`

Sárú an phlean comhbhrúite de réir iarratais. An tosaíocht is airde — sáraíonn sé sárú an teaglama ródaithe, an phróifíl ghníomhach, an t-uath-thruicear, agus Réamhshocrú an phainéil. Luachanna:

| Luach         | Éifeacht                                                                                                                               |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `off`         | Gan aon chomhbhrú don iarratas seo.                                                                                                    |
| `default`     | Próifíl Réamhshocraithe atá díorthaithe ón bpainéal (déanann sí neamhaird den phróifíl ghníomhach). Fágtar innill chaillteacha múchta. |
| `safe`        | Dí-dhúbláil agus fillte spáis bháin amháin.                                                                                            |
| `allow-lossy` | Coinnigh plean an oibreora don iarratas seo, lena n-áirítear achoimrí agus athscríobh stíle.                                           |
| `engine:<id>` | Inneall amháin nuair atá sé cumasaithe, e.g. `engine:rtk`. Rogha de réir iarratais don inneall sin.                                    |
| `<combo>`     | Teaglama ainmnithe, meaitseáilte de réir ainm (gan beann ar chás) ar dtús, agus ansin de réir aitheantais.                             |

Nótaí:

- Déantar neamhaird de luachanna anaithnide (ní dhiúltaítear don iarratas riamh); téann an réiteach ar aghaidh chuig gnáththosaíocht an oibreora.
- Má tá an t-ainm céanna ar níos mó ná teaglama amháin, cuir **id** an teaglama ar fáil chun meaitseáil chinntitheach a fháil.
- Ní féidir teaglama dar ainm `off` nó `default` a roghnú de réir ainm (léirmhínítear na heochairfhocail sin ar dtús); déan tagairt do theaglama den sórt sin lena aitheantas.
- Is geata docht é an máistirlasc comhbhrúite: nuair atá comhbhrú díchumasaithe go domhanda, ní féidir leis an gceanntásc seo é a chumasú.

Déantar an plean a cuireadh i bhfeidhm a mhacasamhlú ar ais i gceanntásc an fhreagra:

```
X-OmniRoute-Compression: <mode>; source=<source>
```

áit a bhfuil `<source>` ar cheann de `request-header`, `routing-override`, `active-profile`, `auto-trigger`, `default`, nó `off`.

## Leabuithe

```bash
POST /v1/embeddings
Authorization: Bearer your-api-key
Content-Type: application/json

{
  "model": "nebius/Qwen/Qwen3-Embedding-8B",
  "input": "The food was delicious"
}
```

Soláthraithe atá ar fáil: Nebius, OpenAI, Mistral, Together AI, Fireworks, NVIDIA, **OpenRouter**, Jina AI.

Is san fhormáid `provider/model` atá aitheantais na catalóige (sampla: `jina-ai/jina-embeddings-v5-omni-small`). Réitítear freisin aitheantais loma shamhla Jina atá sa chlárlann (mar shampla `jina-embeddings-v5-text-small`, `jina-reranker-v3.5`). Úsáideann leabú/athrangú/aicmiú/deighilt Jina dintiúir `jina-ai` an deais ar dtús; ní úsáidtear `JINA_AI_API_KEY` mar chúltaca ach amháin nuair nach bhfuil eochair deaise ann. Is don Reader / `r.jina.ai` amháin atá an cárta `jina-reader` (`POST /v1/web/fetch`) agus ní sholáthraíonn sé leabuithe ná athrangú riamh.

Glacann samhlacha clárlainne a fhógraíonn tacaíocht ilmhódach le suas le 32 mír struchtúrtha
atá neodrach ó thaobh soláthraí de freisin. Is iad na cineálacha míre meán `text`, `image`, `audio`, `video`, agus `document`. Is é `source`
na meán ná `{"type":"url","url":"https://..."}` nó
`{"type":"base64","data":"...","media_type":"..."}`.

Glacann Jina v5 Omni (`jina-ai/jina-embeddings-v5-omni-small`, `jina-ai/jina-embeddings-v5-omni-nano`,
agus ailias an teaghlaigh `jina-ai/jina-embeddings-v5-omni` → omni-small) le cáipéisí dúchasacha
EmbeddingsV5Request de chuid Jina freisin agus **cuireann sé ar aghaidh iad gan athrú** chuig `https://api.jina.ai/v1/embeddings`:

```json
{
  "model": "jina-ai/jina-embeddings-v5-omni-small",
  "task": "retrieval.query",
  "normalized": true,
  "input": [
    { "text": "a red bicycle" },
    { "image": "https://example.com/bike.png" },
    { "content": [{ "text": "caption" }, { "image": "data:image/png;base64,..." }] }
  ]
}
```

Is féidir le luachanna dúchasacha `{ image | audio | video | pdf }` a bheith ina URL poiblí HTTPS, ina URI `data:`, nó ina
mbase64 amh. Ní athraíonn OmniRoute na hoibiachtaí sin ina dteaghráin ná ní fhaigheann sé URLanna dúchasacha íomhánna — faigheann Jina
na meáin phoiblí féin. Cuirtear réimsí breise Jina (`task`, `normalized`, `truncate`, `embedding_type`) ar
aghaidh. Diúltaíonn SKUanna Jina atá téacsamháin fós do cháipéisí nach téacs iad.

Teorainneacha slándála agus iompair:

- Ní mór do URLanna meán cianda a bheith ina HTTPS poiblí. Faightear míreanna canónacha `{type,source:url}`
  ar thaobh an fhreastalaí (athbhailíochtú atreoraithe, teorainn ama, teorainneacha méide, DNS poiblí, pionnáil naisc) agus
  cuirtear isteach inlíne iad roimh ghlao an tsoláthraí. Cuirtear míreanna dúchasacha Jina `{image:"https://..."}` ar aghaidh mar atá siad
  tar éis an tseiceáil chéanna ar HTTPS poiblí; faigheann Jina an URL.
- Tá meáin base64 inlíne teoranta do 8 MiB díchódaithe in aghaidh na míre agus 16 MiB díchódaithe ar fud na hiarrata.

Aistriúchán don soláthraí (ní chuirtear míreanna canónacha ar aghaidh gan athrú riamh):

- Samhlacha ilmhódacha Jina: déantar oibiacht amháin atá eochraithe de réir módúlachta de gach mír ardleibhéil
  (`text` / `image` / `audio` / `video` / `pdf`), agus URIanna sonraí á n-úsáid do mheáin inlíne; veicteoir amháin in aghaidh
  na míre ardleibhéil.
- Teaghlach Gemini Embedding 2: déantar iarratas dúchasach amháin
  `models/{model}:embedContent` d'eagar ardleibhéil amháin le `content.parts` (`text` nó `inline_data`).
- llama.cpp (`llama-cpp/<model>`, aon samhail atá luchtaithe ag an bhfreastalaí áitiúil): déantar gnáth-theaghráin de mhíreanna canónacha `text`,
  agus déantar oibiacht amháin `{"content": [part]}` an ceann de `image` / `audio` / `video`, ag úsáid codanna inneachair comhrá llama-server (`image_url`,
  `input_audio` le formáid `wav` / `mp3` / `flac`, `input_video`) le sonraí inlíne; veicteoir amháin
  in aghaidh na míre ardleibhéil. Ní mór don fhreastalaí a bheith ag rith le `--embedding --mmproj …`; gan teilgeoir,
  diúltaíonn sé do mheáin é féin. Ní thacaítear le `document`.
- Diúltaíonn samhlacha anaithnide/dinimiciúla gan meiteashonraí follasacha módúlachta d'ionchur struchtúrtha le HTTP 400.

```json
{
  "model": "jina-ai/jina-embeddings-v5-omni-small",
  "input": [
    { "type": "text", "text": "A red bicycle" },
    {
      "type": "image",
      "source": { "type": "url", "url": "https://example.com/bicycle.png" }
    }
  ],
  "dimensions": 512,
  "encoding_format": "float"
}
```

Tugann teaglamaí samhla/módúlachta nach dtacaítear leo HTTP 400 ar ais seachas an mhír a chomhéigniú. Leanann réimsí
sínte nach réimsí ionchuir iad ar iarratais oidhreachta teaghráin/comharthaí de bheith curtha ar aghaidh gan athrú.

```bash
# Liostaigh gach samhail leabaithe
GET /v1/embeddings
```

```bash
POST /v1/images/generations

{
```

I measc na soláthraithe atá ar fáil tá OpenAI (GPT Image 2), xAI (Grok Image), Together AI (FLUX), Fireworks AI, Nebius (FLUX), Hyperbolic, NanoBanana, **OpenRouter**, **ZenMux**, SD WebUI (áitiúil), ComfyUI (áitiúil).

Filleann `n` líon `n` íomhánna in `data[]`. I gcás soláthraithe a bhfilleann a n-API réamhtheachtach íomhá amháin in aghaidh an ghlao

NVIDIA NIM, Cloudflare Workers AI), déantar `n` glao réamhtheachtach ar leith, agus 4 cinn ar a mhéad ar bun ag an am céanna. Déantar
`seed` seasta a fhritháireamh de réir innéacs an ghlao (`seed`, `seed + 1`, …), ionas go mbeidh na híomhánna éagsúil ach go mbeidh siad
in-atáirgthe. Tá `n` teoranta do 10. Teipeann ar an iarratas ina iomláine má theipeann ar aon ghlao. Is é
`SINGLE_IMAGE_FANOUT_FORMATS` in
`open-sse/handlers/imageGeneration/fanOut.ts` liosta na bhformáidí leathnaithe.

Athúsáideann ZenMux an nasc eochrach API atá ann cheana agus glacann sé le réimíreanna `zenmux/` nó `zm/`:

- Úsáideann `zenmux/openai/gpt-image-2` API Íomhánna OpenAI de chuid ZenMux. I measc na roghanna tá `size`,
  `quality`, `n`, `output_format`, `output_compression`, `background`, agus `response_format`.
- Úsáideann foilsitheoirí eile, amhail `zm/meta/muse-image-1.0`, críochphointe Vertex AI `:predict`

- Roghnaíonn `zm/inclusionai/ming-image-0.1-design` a thoisí féin. Fág `size`,
  `aspect_ratio`, agus `image_size` ar lár; filleann luachanna sainráite HTTP 400. Is féidir PNG, JPEG, agus WebP
  a iarraidh le `output_format`.

Tacaíonn an comhtháthú seo le giniúint téacs-go-híomhá, ní le heagarthóireacht íomhá thagartha. Déantar aschur Vertex

earráid seachas freagra rathúil folamh. Braitheann rochtain ar shamhlacha ar chuntas ZenMux.

```bash

{
  "model": "mistral/mistral-ocr-latest",
```

Roghnaíonn `model` an soláthraí OCR trí réimír `provider/model`; réitítear aitheantas samhla lom (m.sh.

Mistral (`mistral-ocr-latest`) mar réamhshocrú. Soláthraithe cláraithe (`open-sse/config/ocrRegistry.ts`):

| Aitheantas soláthraí          | Aitheantas samhla    | Luach `model`                                              | Nótaí                                                                                                                       |
| ----------------------------- | -------------------- | ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `mistral`                     | `mistral-ocr-latest` | `mistral/mistral-ocr-latest` (nó `mistral-ocr-latest` lom) | Sioncronach — filleann an freagra go díreach ón nglao réamhtheachtach aonair.                                               |
| `azure-document-intelligence` | `prebuilt-read`      | `azure-document-intelligence/prebuilt-read`                | Réamhtheachtaí aisioncronach (`analyze` + fiosrú) — féach thíos.                                                            |
| `vertex-deepseek-ocr`         | `deepseek-ocr-maas`  | `vertex-deepseek-ocr/deepseek-ocr-maas`                    | Sioncronach, trí chríochphointe comhpháirtí `openapi/chat/completions` Vertex AI — féach thíos maidir le fíordheimhniú/URL. |

```json
{
  "pages": [{ "index": 0, "markdown": "# Extracted text..." }],
  "model": "mistral-ocr-latest",
  "usage_info": { "pages_processed": 1 }
}
```

### Sreabhadh fiosraithe Azure Document Intelligence

Tá API `analyze` Azure Document Intelligence aisioncronach: filleann an t-iarratas tosaigh ceanntásc
`Operation-Location` in ionad coirp, agus ní mór an toradh a fhiosrú. Déanann an láimhseálaí
(`open-sse/handlers/ocr.ts`) an URL sin a fhiosrú gach soicind ar feadh suas le 30 iarracht, teipeann sé láithreach (ní
leanann sé den fhiosrú) nuair a fhaightear freagra fiosraithe nach bhfuil `ok` nó stádas `"failed"`, agus filleann sé `504` má tá an
oibríocht fós ar siúl tar éis an líon ceadaithe iarrachtaí a ídiú. Déantar freagra deiridh Azure a
normalú go dtí an cruth céanna `pages`/`markdown` a úsáideann Mistral sula bhfilltear ar an
nglaoiteoir é, mar sin ní gá do chód an chliaint an soláthraí a láimhseáil mar chás speisialta.

### Fíordheimhniú agus réiteach críochphointe Vertex AI DeepSeek OCR

Athúsáideann `vertex-deepseek-ocr` an fíordheimhniú Vertex AI céanna a dtacaíonn OmniRoute leis cheana féin le haghaidh
tráchta comhrá/íomhá (`open-sse/executors/vertex.ts`): is é eochair API an naisc dintiúr JSON
Cuntais Seirbhíse (a mhalartaítear ar chomhartha rochtana OAuth gearrshaolach trí shreabhadh JWT-bearer)
nó comhartha rochtana OAuth atá eisithe cheana agus a úsáidtear mar atá. Is é URL an chríochphointe réamhtheachtaigh críochphointe comhpháirtí ginearálta
`openapi/chat/completions` Vertex, a chruthaítear ó thionscadal agus réigiún an naisc —
bíonn tosaíocht i gcónaí ag `providerSpecificData.project`/`providerSpecificData.region` sainráite;
seachas sin, díorthaítear an tionscadal ó `project_id` JSON an Chuntais Seirbhíse agus úsáidtear
`us-central1` mar réamhshocrú don réigiún. Tarlaíonn an dá réiteach in `open-sse/handlers/ocr.ts`
(`resolveVertexOcrAccessToken`, `resolveVertexOcrBaseUrl`), agus úsáideann
`src/app/api/v1/ocr/route.ts` iad sula seoltar chuig `handleOcr`.

### Réimíreanna aitheantais samhla (`?prefix=`)

Fógraítear formhór na samhlacha faoi **réimír soláthraí**. Is í an bhratach gné
`MODELS_CATALOG_PREFIX_MODE` a rialaíonn cén réimír a gheobhaidh tú, agus is féidir í a shárú
**do gach iarratas ar leith** le paraiméadar iarratais — rud atá úsáideach do chliant ar mian leis
liosta glan a fháil gan an socrú ar fud an fhreastalaí a athrú do gach duine eile:

```bash

GET /v1/models?prefix=dual         # an dá fhoirm (réamhshocrú an fhreastalaí)
GET /v1/models?prefix=canonical    # réimír iomlán aitheantais an tsoláthraí amháin
```

| Mód         | Astaíonn                                                   | Nótaí                                                                                                                                                                                                                                                |
| ----------- | ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

### Scagairí aimsithe (`?capability=`, `?min_context=`, `?kind=`, `?q=`)

Glacann `GET /v1/models` le scagairí aimsithe roghnacha. Gan aon cheann acu, ní athraítear
an freagra. Caolaíonn siad an chatalóg a fheiceann an glaoiteoir cheana féin (cuirtear ceadanna
eochrach API i bhfeidhm ar dtús), agus ritear iad roimh leathanachú `limit` / `after` ar stíl OpenAI:

```bash
GET /v1/models?capability=vision&capability=tool_calling   # ní mór do gach cumas liostaithe a bheith fíor
GET /v1/models?capability=vision,reasoning&min_context=200000
GET /v1/models?kind=embedding                              # `type` na catalóige; is `chat` iad rónna nach bhfuil ceann acu
GET /v1/models?q=sonnet&limit=10                           # meaitseáil nach ndéanann idirdhealú idir cásanna ar aitheantas nó ainm
```

| Paraiméadar   | Luachanna                                                                                           |
| ------------- | --------------------------------------------------------------------------------------------------- |
| `capability`  | `attachment`, `reasoning`, `structured_output`, `temperature`, `thinking`, `tool_calling`, `vision` |
| `min_context` | slánuimhir neamh-dhiúltach, curtha i gcomparáid le `context_length`                                 |
| `kind`        | `chat`, `audio`, `embedding`, `image`, `moderation`, `music`, `rerank`, `video`                     |
| `q`           | 1–200 carachtar                                                                                     |

I gcás luacha anaithnid, nó `min_context` nach slánuimhir neamh-dhiúltach é (mar shampla `1.5`),
seoltar HTTP `400` ar ais agus liostaítear na luachanna bailí sa teachtaireacht. Cur i bhfeidhm:
`src/app/api/v1/models/catalogFilters.ts`.

### Gearrliosta samhlacha (`POST /v1/models/query`)

Filleann `POST /v1/models/query` liosta gearr, cinntitheach ón gcatalóg chéanna, leis an bhfíordheimhniú
agus an infheictheacht chéanna in aghaidh na heochrach agus atá ag `GET /v1/models`:

```bash
POST /v1/models/query
Authorization: Bearer your-api-key
Content-Type: application/json

{ "capabilities": ["vision", "tool_calling"], "min_context": 128000, "max_output": 16000,
  "kind": "chat", "q": "gpt", "owned_by": "openai", "exclude": ["openai/gpt-4o"], "limit": 5 }

→ { "object": "list", "data": [ ...models ] }
```

Tá gach réimse roghnach. Glacann `capabilities` agus `exclude` le heagar nó teaghrán deighilte
le camóga; cuireann `max_output` i gcomparáid le `max_output_tokens`. Sórtáiltear torthaí de réir
`owned_by`, agus ansin de réir `id`. Is é `20` réamhshocrú `limit`, agus cuirtear uasteorainn `100`
le luachanna os cionn `100`. Seoltar HTTP `400` ar ais i gcás JSON neamhbhailí, réimse anaithnid
nó luach neamhbhailí.

### Samhlacha comhrá folaithe ar leithligh

Eisiatar samhail atá marcáilte mar **Fholaithe** ar leathanach a soláthraí ón gcatalóg agus diúltaítear
di le HTTP `404` / `model_not_found` nuair a iarrtar go sainráite í. Úsáideann an tseiceáil an soláthraí
agus an tsamhail réitithe, lena n-áirítear ailiasanna soláthraí, réimíreanna nóid soláthraí chomhoiriúnaigh,
agus réamhshocruithe ceangail. Scipeálann comhcheangal spriocanna folaithe agus is féidir leis samhail
infheicthe ghaolmhar a úsáid; nuair nach mbíonn aon sprioc inrite fágtha aige, seolann sé an cód earráide
céanna ar ais. Tagann an dífholú i bhfeidhm leis an gcéad iarratas eile. Ní fholaíonn sáruithe
infheictheachta d’íomhánna amháin an tsamhail chomhrá a bhfuil an t-aitheantas céanna aici.

Tá an socrú seo do shamhail aonair ar leithligh ó na
[liostaí ceadaithe/diúltaithe um nochtadh samhlacha](../routing/MODEL_EXPOSURE_LIST.md), a scagann
fógraíocht na catalóige agus iarrthóirí uathródaithe agus seoladh sainráite á choinneáil acu. Leanann
ceadanna samhla eochrach API de bheith i bhfeidhm go neamhspleách. Is é `dual` mód réamhshocraithe
réimír na catalóige fós.

### Leaganacha samhla gan smaointeoireacht

I gcás samhlacha Claude atá in ann smaointeoireacht a dhéanamh, fógraíonn `/v1/models` leagan
**gan smaointeoireacht** freisin a bhfuil `claude-3-omniroute-no-thinking/` mar réimír ar a aitheantas:

```
claude-3-omniroute-no-thinking/<provider>/<model>
```

Má roghnaítear an t-aitheantas seo (m.sh. i gcumraíocht Claude Code a cheanglaíonn bloc `thinking` i gcónaí), réitítear ar ais é go dtí an fíor-aitheantas `<provider>/<model>` agus an réasúnaíocht faoi chois — `thinking:{type:"disabled"}` ar an gcosán `/v1/messages`, nó fágtar na réimsí `reasoning`/`reasoning_effort` ar lár ar an gcosán `/v1/chat/completions`. Ní liostaítear an leagan malartach ach amháin do shamhlacha de theaghlach Claude a thacaíonn le smaointeoireacht **agus** a urramaíonn `disabled` (mar sin, e.g. eisiatar samhlacha oiriúnaitheacha amháin a dhiúltaíonn do `disabled`). Is féidir le hoibreoirí an leagan malartach a chumasú nó a dhíchumasú go héigeantach do gach samhail trí `ModelSpec.noThinkingAlias`.

## Giniúint fuaime ElevenLabs

Cumraigh nasc soláthraí `elevenlabs` in OmniRoute le d'eochair API ElevenLabs.
Fíordheimhníonn cliaint lena n-eochair **OmniRoute** (`Authorization: Bearer $OMNIROUTE_API_KEY`);
soláthraíonn an geata eochair stóráilte an tsoláthraí mar `xi-api-key`. Ná seol eochair ElevenLabs riamh
mar chomhartha iompróra an gheata.

| Modh | Conair                      | Freagra                                                 | Catagóir chríochphointe na heochrach API |
| ---- | --------------------------- | ------------------------------------------------------- | ---------------------------------------- |
| POST | `/v1/sound-generation`      | Bearta fuaime dúchasacha                                | `elevenlabs`                             |
| POST | `/v1/music`                 | Bearta fuaime dúchasacha                                | `music`                                  |
| POST | `/v1/music/stream`          | Bearta fuaime sruthaithe                                | `music`                                  |
| POST | `/v1/music/detailed`        | Fuaim ilpháirteach dhúchasach agus plean cumadóireachta | `music`                                  |
| POST | `/v1/music/detailed/stream` | Meiteashonraí SSE dúchasacha agus smutáin fuaime        | `music`                                  |
| POST | `/v1/music/plan`            | Plean cumadóireachta JSON                               | `music`                                  |

Comhlánaíonn na críochphointí seo na bealaí reatha `/v1/audio/speech`, `/v1/audio/transcriptions`,
`/v1/voices`, `/v1/text-to-speech/{voiceId}` agus `/v1/speech-to-text`. Caomhnaítear réimsí JSON
dúchasacha agus paraiméadair iarratais amhail `output_format` agus `enable_logging`.
Coinníonn freagraí `/v1/music/detailed` a dteorainneacha ilpháirteacha; parsáil mar ábhar ilpháirteach iad.
Filleann `/v1/music/detailed/stream` `text/event-stream` ina bhfuil meiteashonraí cumadóireachta agus
smutáin fuaime base64 in imeachtaí SSE. Tacaíonn na sé bhealach ar fad le réamhiarratais CORS.

```bash
export OMNIROUTE_BASE_URL="http://localhost:20128"
export OMNIROUTE_API_KEY="your-omniroute-api-key"

# Maisíocht fuaime ghearr. Fad: 0.5 go 30 soicind.
curl --fail-with-body "$OMNIROUTE_BASE_URL/v1/sound-generation?output_format=mp3_44100_128" \
  -H "Authorization: Bearer $OMNIROUTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text":"A single soft bell chime","duration_seconds":1,"model_id":"eleven_text_to_sound_v2"}' \
  --output effect.mp3

# Sloinntear fad an cheoil i milleasoicindí: 3000 go 600000.
curl --fail-with-body "$OMNIROUTE_BASE_URL/v1/music?output_format=mp3_44100_128" \
  -H "Authorization: Bearer $OMNIROUTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"Gentle instrumental piano","music_length_ms":10000,"force_instrumental":true,"model_id":"music_v1"}' \
  --output music.mp3
```

Úsáid `/v1/music/stream` leis an gcorp JSON céanna chun fuaim a sheachadadh de réir a chéile. Glacann an chumadóireacht
le ceann amháin go díreach de `prompt` nó `composition_plan`; éilíonn `/v1/music/plan` `prompt`
agus glacann sé go roghnach le `source_composition_plan`. Caomhnaíonn na scéimeanna dúchasacha réimsí breise
soláthraí ionas go sroichfidh leaganacha de phleananna cumadóireachta agus roghanna mionchoigeartaithe ElevenLabs.

Glacann an críochphointe aontaithe `/v1/music/generations` le `elevenlabs/music_v1`,
`elevenlabs/music_v2` agus `elevenlabs/music_v2_5` freisin. Le nasc gníomhach ElevenLabs,
nochtar na samhlacha seo sa chatalóg cheoil. Filleann an críochphointe seo
`{"created":...,"data":[{"b64_json":"...","format":"mp3"}]}`. Tá a réimse `duration` i
soicindí agus mapáiltear é chuig `music_length_ms`; tugtar tús áite do `music_length_ms` follasach.
Mapáiltear `instrumental` chuig `force_instrumental`, agus tugtar tús áite don réimse dúchasach.
Úsáid na críochphointí sruthaithe dúchasacha le haghaidh sruthaithe agus an críochphointe cumadóireachta dúchasach
le haghaidh iarratais atá á dtiomáint ag plean cumadóireachta amháin.

```bash
curl --fail-with-body "$OMNIROUTE_BASE_URL/v1/music/generations" \
  -H "Authorization: Bearer $OMNIROUTE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"elevenlabs/music_v1","prompt":"Gentle instrumental piano","duration":10,"instrumental":true}'
```

Cuirtear srianta críochphointe, samhla, buiséid agus naisc i bhfeidhm roimh ghlao réamhtheachtach. Filleann bealaí
dúchasacha cóid stádais agus coirp earráide ón réamhtheachtaire gan athrú, lena n-áirítear `402` do shrian plean
agus `429` do theorainn cuóta. Caomhnaítear na ceanntásca `character-cost`, `song-id`, `request-id` agus `retry-after`
nuair atá siad i láthair. Ní ráthaíonn iarmhéid creidmheasa saor in aisce rochtain ar gach
samhail cheoil, formáid aschuir ná gné API: cinneann ElevenLabs an teidlíocht do gach iarratas.
Caomhnaíonn an críochphointe aontaithe cóid stádais earráide i gclúdach earráide normalaithe OmniRoute.

Conarthaí réamhtheachtacha: [maisíochtaí fuaime](https://elevenlabs.io/docs/api-reference/text-to-sound-effects/convert),
[cumadóireacht cheoil](https://elevenlabs.io/docs/api-reference/music/compose) agus
[mionsonraí ceoil sruthaithe](https://elevenlabs.io/docs/api-reference/music/compose-detailed-stream).

> **Nóid soláthraí athrangaithe:** seoltar `POST /v1/rerank` freisin chuig nóid soláthraí atá comhoiriúnach le OpenAI
> (oMLX, vLLM, Infinity, TEI taobh thiar de gheata, …) a seoltar chucu mar `<node-prefix>/<model>`. Bíonn nóid
> lúb-ais (`localhost`, `127.0.0.1`, `172.16.0.0/12`) incháilithe i gcónaí, mar a bhíonn óstainmneacha a
> liostaíonn an t-oibreoir in `OMNIROUTE_LOCAL_PROVIDER_NODE_HOSTS` (m.sh. ainm seirbhíse Docker/Compose
> amhail `http://reranker:8080/v1`; glaoitear orthu seo go díreach, agus ní trí `HTTP(S)_PROXY` ná trí
> sheachfhreastalaí feistithe naisc riamh). Ní bhíonn nóid ar aon
> óstach eile — bosca LAN nó piara Tailscale — incháilithe ach amháin nuair a chumasaíonn an t-oibreoir
> an bhratach ghné `RERANK_REMOTE_PROVIDER_NODES` **agus** nuair a éiríonn le bun-URL an nóid de réir
> bheartas URL amach an tsoláthraí (`OMNIROUTE_ALLOW_LOCAL_PROVIDER_URLS` / `OMNIROUTE_ALLOW_PRIVATE_PROVIDER_URLS`).
> Glaonn céim athrangaithe an innill chuimhne ar an mbealach seo thar
> lúb-ais, mar sin rialaíonn an riail chéanna `rerankProviderModel` sna socruithe Cuimhne.
>
> **Cruthanna freastalaí áitiúil:** glaoitear ar an nód ag `<base>/v1/rerank` agus, i gcás 404, ag `<base>/rerank`
> (Infinity, TEI). Bíonn litriú Cohere/OpenAI (`documents`,
> `return_documents`) agus litriú TEI (`texts`, `return_text`) araon sa chorp réamhtheachtach, agus
> normalaítear an freagra réamhtheachtach chuig imchlúdach Cohere: tagann liosta lom TEI
> `[{index, score, text}]`, `{results: [{index, score}]}` ó gheataí tanaí, agus `{data: [...]}` de stíl
> Voyage ar ais chuig an gcliant mar `{results: [{index, relevance_score, document?}]}`, sórtáilte de
> réir scóir agus teoranta ag `top_n`.

> **Aimsiú nód soláthraí:** bíonn samhlacha ar nód soláthraí atá comhoiriúnach le OpenAI le feiceáil in `GET /v1/models`
> faoi réimír an nóid. Faigheann sraitheanna nach bhfuil meiteashonraí críochphointe acu (rud is gnách i liostaí áitiúla
> `/v1/models`) `apiType` an nóid le hoidhreacht, ionas gur `type: "embedding"` iad samhlacha nóid
> `embeddings` agus gur `type: "rerank"` iad samhlacha nóid `rerank`, seachas comhrá a úsáid mar
> réamhshocrú; bíonn tosaíocht fós ag `supportedEndpoints` sainráite ar shraith shioncronaithe nó curtha
> leis de láimh.

nach féidir an spriocleathanach féin a bhaint amach, tuairiscíonn an tseirbhís réamhtheachtach é laistigh de HTTP 200;
cuireann OmniRoute é sin ar fáil mar `422` le teachtaireacht sheasta.

| ---- | --------------- | --------------------------------------------------------------- |

**Cúltaca atá feasach ar chuóta (#8297):** nuair nach dtugtar `provider` follasach, téitear tríd an linn
(`firecrawl` → `jina-reader` → `tavily-search` → `tinyfish` → `nimble-search` →
`parallel-search`) in ord seasta
tosaíochta (líon-an-chéad-cheann-ar-dtús) — scipeáiltear soláthraí atá cumraithe ach srianta de réir ráta
seachas an t-iarratas a ghearrchiorcadú, agus i gcás teipe in-atriailte/cuóta ón tseirbhís réamhtheachtach
(HTTP 429 i gcónaí; 402/403 do shraitheanna saora de chineál cuóta Firecrawl/Tavily/TinyFish —
ní do Jina Reader, agus ní riamh d’iarratas neamhbhailí simplí 400), téitear ar aghaidh chuig an
gcéad soláthraí eile nár baineadh triail as agus a bhfuil dintiúir aige ag am an iarratais. Nuair a bhíonn gach soláthraí sa
linn ídithe, tugann an críochphointe `429` amháin ar ais (le ceanntásc `Retry-After`)
in ionad an `400` chineálaigh roimhe seo. Nuair a iarrtar `provider` follasach,
níl **aon** chúltaca ciúin ann — cuirtear earráid an tsoláthraí fhollasaigh féin ar fáil má tá sé
srianta de réir ráta nó má theipeann air (`429` má tá sé srianta de réir ráta, nó stádas na seirbhíse
réamhtheachtaí murach sin).

## Úsáid féinseirbhíse (`/api/usage/om-usage`)

Is féidir le haon eochair API a húsáid agus a cuótaí **féin** a léamh — níl fíordheimhniú bainistíochta de dhíth. Seo é an críochphointe a

```bash
curl -H "Authorization: Bearer <your-api-key>" \
  http://localhost:20128/api/usage/om-usage

# Foirm struchtúrtha — an méid a úsáideann UI

  "http://localhost:20128/api/usage/om-usage?format=json"
```

Ní mór **`allowUsageCommand`** a bheith cumasaithe don eochair (díchumasaithe de réir réamhshocraithe — scoránaíonn bainisteoir eochracha API
an deais é do gach eochair ar leith). Gan é, freagraíonn an críochphointe le `403`.

Filleann `?format=json` cruth idirdhealaithe ionas nach léifidh glaoiteoir réimse sonraí ó
dhiúltú choíche. Ar éirigh leis:

```jsonc
{
  "allowed": true,
  // níl sé seo i láthair ach nuair a roghnaigh an eochair teorainneacha úsáide in aghaidh na heochrach (USD laethúil/seachtainiúil):
  "personal": {
    "dailySpentUsd": 1.25,
    "dailyLimitUsd": 5,
    "dailyResetAtIso": "…",
    "weeklySpentUsd": 8,
    "weeklyLimitUsd": 20,
    "weeklyResetAtIso": "…" /* … */,
  },
  // léargas cuóta an tsoláthraí roghnaithe, nó null nuair nach bhfuil aon rud i dtaisce go fóill:
  "provider": { "connectionId": "…", "provider": "claude", "plan": "…", "quotas": {/* … */} },
  // léargas gach naisc, ionas gur féidir le UI roinnt soláthraithe a rindreáil taobh le taobh:
  "providers": [
    { "connectionId": "…", "provider": "claude" /* … */ },
```

### Céatadáin Chuóta Amha i gComparáid le Céatadáin atá Coigeartaithe don Tairseach Scoite

Agus `/api/usage/om-usage` á úsáid, ba cheart do ghlaoiteoirí an difríocht idir na
céatadáin a chuirtear i láthair san **aschur gnáth-théacs** agus san **aschur struchtúrtha JSON** a thabhairt faoi deara:

| Gné                 | Formáid gnáth-théacs (`/api/usage/om-usage` / `@@om-usage`)                                                | Formáid JSON (`?format=json`)                                                         |
| :------------------ | :--------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------ |
| **Réimse aschuir**  | `NN% left` (m.sh., `20% left`)                                                                             | `provider.quotas` / `providers[].quotas`                                              |
| **Tomhas**          | **Liúntas inúsáidte coigeartaithe don tairseach scoite**: an acmhainn atá fágtha os cionn na tairsí scoite | **Cuóta amh réamhtheachtach**: tomhas neamhchoigeartaithe an tsoláthraí               |
| **Scálú scoite**    | Scálaithe trí `effectiveRemainingPercent()` ionas go léitear an cúlchiste cosanta mar `0% left`            | Dada (luachanna léargais amha mar a thuairiscíonn an soláthraí iad)                   |
| **Sonraí tairsí**   | Ionchorpraithe sa chéatadán a thaispeántar                                                                 | Stóráilte in `quotaWindowThresholds` do gach nasc (nó réamhshocruithe an fhreastalaí) |
| **Príomhúsáideoir** | CLIanna idirghníomhacha, leideanna teirminéil, oibreoirí daonna                                            | Comhtháthuithe ríomhchláraithe, deaiseanna, anailísíocht, rianairí billeála           |

#### Foirmle an Choigeartaithe don Tairseach Scoite

Tacaíonn OmniRoute le tairseacha réamhghníomhacha cuóta chun ídiú réamhtheachtach a chosc (cumraithe trí
`quotaWindowThresholds` an naisc, réamhshocruithe an tsoláthraí, nó socruithe domhanda athléimneachta). Nuair atá tairseach scoite
(m.sh., `cutoff = 25%`) gníomhach ar fhuinneog chuóta, ríomhann an rindreálaí téacs an liúntas atá fágtha mar seo:

- Má tá `remaining <= cutoff`: filleann sé `0%`.
- Má tá `remaining > cutoff`: filleann sé `((remaining - cutoff) / (100 - cutoff)) * 100`.

Slánaíonn an t-aschur téacs formáidithe é seo go dtí an tslánuimhir is gaire (`Math.round(...)`).

#### Sampla Léiritheach

Samhlaigh fuinneog soláthraí ina bhfuil **60% d'úsáid amh** (agus mar sin **40% den chuóta amh fágtha**) agus
**tairseach scoite 25% den chuóta atá fágtha** cumraithe:

| Léiriú                         | Ríomh                                              | Fágtha  |             Úsáid Intuigthe             |
| :----------------------------- | :------------------------------------------------- | :-----: | :-------------------------------------: |
| **JSON amh (`?format=json`)**  | Léargas réamhtheachtach (`quotas[window]`)         | **40%** |                 **60%**                 |
| **Formáid téacs (`NN% left`)** | `((40 - 25) / (100 - 25)) * 100 = (15 / 75) * 100` | **20%** | **80%** (má ríomhtar `100 - remaining`) |

- **Cén fáth a léiríonn an téacs 20% fágtha:** As an 40% den chuóta fisiciúil atá fágtha sa chuntas, tá 25% curtha in áirithe ag an
  bpolasaí scoite. Níl ach 15% as 75% den spás inúsáidte fágtha ag an nglaoiteoir sula stopfaidh an ródaire
  ag ródú chuig an nasc seo. Cinntíonn an scálú go léiríonn an nasc ídiú (`0% left`) go díreach nuair a
  chuirfear deireadh leis an ródú.
- **Cén fáth a gcaomhnaíonn JSON na luachanna amha:** Filleann an pálasta JSON léargas beacht an tsoláthraí (`UsageSnapshot`)
  ionas go mbeidh rochtain ag uirlisí seachtracha ar fhíorluachanna na húsáide réamhtheachtaí agus ar
  `quotaWindowThresholds` ar leibhéal an naisc gan scálú caillteach ar thaobh an fhreastalaí.

#### Treoir Aistrithe d'Úsáideoirí

Má rinne comhtháthú seachtrach (amhail breiseán eagarthóra nó síneadh gníomhaire) téacs an
chríochphointe (`NN% left`) a scríobadh roimhe seo agus má ríomh sé an céatadán a úsáideadh mar `100 - NN`, ciallaíonn aistriú go `?format=json`:

- Léireoidh léamh na n-amhluachanna JSON an **tomhaltas iarbhír réamhtheachtach** (60% úsáidte sa sampla thuas).
- Más mian leis an gcomhtháthú séimeantaic an liúntais inúsáidte ó chríochphointe an téacs a chaomhnú, féadfaidh sé
  foirmle éifeachtach an mhéid atá fágtha a mheas ar thaobh an chliaint trí `quotaWindowThresholds` a úsáid le haghaidh sáruithe ar leibhéal an naisc.

gnátheochracha API tátail. Teaghlaigh dintiúr, scóip agus samplaí curl:
[Fíordheimhniú Bainistíochta](../guides/MANAGEMENT-AUTH.md).

I gcás samhlacha sioncronaithe/iompórtáilte, glacann `PUT /api/provider-models` le `provider`, `modelId`, agus
`maxOutputTokenOverride`: socraíonn slánuimhir dheimhneach an uasteorainn láimhe ar chomharthaí aschuir, agus glanann `null`
í chun an réamhshocrú a athbhunú. Tugann `GET /api/provider-models?provider=<provider>` na
luachanna seo ar ais in `modelOutputOverrides`, lena n-áirítear samhlacha nach bhfuil ró samhla saincheaptha acu. Úsáideann an sárú
an cumas ama rite `max_output_tokens` agus maireann sé tar éis samhail a athshioncronú. Cuireann leathanach an tsoláthraí atá comhoiriúnach le OpenAI
na rialuithe céanna eagarthóireachta/glanta ar fáil agus marcálann sé samhlacha a bhfuil tacaíocht fhollasach amhairc acu.

Cuireann nóid shaincheaptha Chat Completions roghanna follasacha chun diúltú do réasúnú in oiriúint don inneall cúil réamhtheachtach. Roghnaíonn
tástáil cheangail rathúil rialuithe teimpléid comhrá go huathoibríoch do gach aitheantas beacht samhla
a gcruthaíonn a iontráil `/models` luach aitheanta `owned_by`: `vllm`, `sglang`, nó `llamacpp`.
Féadfaidh cumhdaigh thrédhearcacha atá comhoiriúnach le OpenAI an iontráil bhunaidh samhla a chaomhnú taobh istigh d'oibiacht neadaithe
`openai`; leanann an bhrath suas le trí chumhdach den sórt sin. Coinníonn samhlacha a bhfuil úinéireacht ar iarraidh, anaithnid nó
choinbhleach acu gnáthiompar OpenAI. Athúsáideann an bhrath an t-iarratas catalóige atá ann cheana,
ní ghineann sé aon chomharthaí comhlánaithe, agus déantar é a neamhbhailíochtú nuair a athraíonn críochphointe an cheangail.

Chun an t-iompar a shocrú go docht d'inneall cúil nach nochtann na meiteashonraí sin, úsáid an API nuashonraithe pháirtigh
soláthraí atá ann cheana:

```json
{
  "providerSpecificData": {
    "reasoningControl": "chat-template"
  }
}
```

Seol an corp sin le `PUT /api/providers/<connection-id>`. Ar an gceangal sin, seoltar iarracht fhollasach
réasúnaithe de `none` mar `chat_template_kwargs.thinking=false` agus
`chat_template_kwargs.enable_thinking=false`. Fanann luachanna follasacha dúchasacha teimpléid ceannasach
mura gcuireann riail réasúnaithe ar thaobh an fhreastalaí leibhéal iarrachta i bhfeidhm. Ní bhaineann an socrú ach amháin nuair a
sheolann ceangal saincheaptha atá comhoiriúnach le OpenAI corp Chat Completions; coinníonn iarratais Responses agus gnáthsholáthraithe
a gcruth dúchasach iarratais. Socraigh `reasoningControl` mar `openai` chun gnáthsheoladh tríd OpenAI
`reasoning_effort` a éigean, nó fág ar lár é/socraigh mar `null` é chun brath uathoibríoch a úsáid.

I gcás iarratais aicmitheora uathmhóid Claude Code, socraítear smaointeoireacht dhúchasach mar dhíchumasaithe de réir réamhshocraithe nuair nach mbíonn
aon rialuithe follasacha réasúnaithe iontu. Úsáideann an bhrath marcóir córais an aicmitheora in iarratais i bhformáid Claude,
seachas ainmneacha samhlacha nó teorainneacha comhlánaithe. Coinníonn rialuithe follasacha coirp, ceanntásca tacaithe iarrachta/smaointeoireachta,
rialacha ródaithe, agus iarracht réitithe na samhla an tosaíocht atá acu cheana. Coinníonn an dá chéim den aicmitheoir
a gcuid leideanna, teorainneacha comhlánaithe, seichimh stad, agus fíorbhreithiúnais cheada ón gcóras réamhtheachtach;
is féidir leis an dara céim fós an réasúnú infheicthe a iarradh a tháirgeadh mar ghnáth-théacs.

faigheann dintiúr meaisín `403` ansin freisin; seolann `omniroute sync import` dintiúr áitiúil an CLI.
Tá an rud céanna fíor maidir le `DELETE /api/db-backups` (cúltacaí stóráilte a bhearradh) agus
`PATCH /api/db-backups` (socruithe coinneála: rialaíonn na luachanna marthanacha an bearradh
uathoibríoch tar éis gach cúltaca). Coinníonn liostú (`GET`) agus cruthú cúltaca de láimh (`PUT`)
an gnáthfhíordheimhniú bainistíochta.

### Leagan agus Cainéal Eisiúna

```bash
GET /api/system/version
```

Bealach bainistíochta lúb-ais amháin (fíordheimhniú riarthóra). Filleann sé an leagan atá á rith, an leagan foilsithe is déanaí agus stádas an nuashonraithe uathoibríoch. Is réimsí breisitheacha iad `releaseChannel` agus `channels` (rian 3.8.54); coinníonn `channel` a bhrí — an modh imscartha a úsáideann nuashonraitheoir an deais (`npm`, `source` nó `docker-compose`).

```json
{
  "current": "3.8.52",
  "latest": "3.8.52",
  "updateAvailable": false,
  "channel": "npm",
  "autoUpdateSupported": true,
  "autoUpdateError": null,
  "news": null,
  "releaseChannel": "latest",
  "channels": { "latest": "3.8.52", "next": "3.8.53-rc.1" }
}
```

- `releaseChannel` — cainéal npm na tógála atá á rith: `nightly` do leaganacha `-nightly.*`,
  `next` do réamheisiúintí eile (`-rc.*`, `-beta.*`, `-alpha.*`), `lts` do leagan cobhsaí de
  mhórleagan níos sine ná `channels.latest`, agus `latest` murach sin. Na rialacha céanna le
  `scripts/release/dist-tag.mjs`, a roghnaíonn dist-tag npm tráth an fhoilsithe.
- `channels` — an leagan foilsithe is déanaí de gach dist-tag, ó `npm view omniroute dist-tags`
  (cúltaca HTTP na clárlainne), curtha i dtaisce leis an TTL 10 nóiméad céanna le `latest`. Bíonn
  `latest` ann i gcónaí (téann sé siar chuig an réimse `latest`, ansin chuig `"unavailable"`);
  ní bhíonn `next`, `nightly` ná `lts` ann ach amháin nuair atá an dist-tag sin ann. Déanann
  iarratas `Cache-Control: no-cache` an dá chuardach a athnuachan.

Déantar cur síos ar mhúnla na gcainéal (`latest` = v3 go dtí infhaighteacht ghinearálta 4.0,
`next` = rc, `nightly` = tógálacha `develop`, `lts` = paistí v3 tar éis infhaighteacht
ghinearálta 4.0) in `docs/ops/RELEASE_STRATEGY.md`.

## Teorainneacha Comharthaí

Buiséid **chomharthaí** in aghaidh na heochrach API (ar leith ón mBuiséad bunaithe ar USD thuas). Cuirtear i bhfeidhm go hinlíne iad ar chonair na n-iarratas: nuair a shroicheann úsáid fuinneoige reatha eochrach a teorainn, diúltaítear d’iarratais le `429 Too Many Requests`. Is féidir teorainneacha a scópáil chuig `model` ar leith, chuig `provider`, nó iad a chur i bhfeidhm go `global` ar fud na heochrach; nuair a mheaitseálann roinnt teorainneacha iarratas, bíonn forlámhas ag an gceann is sriantaí.

```bash
# Liostaigh teorainneacha comharthaí eochrach (lena n-áirítear úsáid bheo na fuinneoige)
GET /api/usage/token-limits?apiKeyId=key-123

# Cruthaigh nó nuashonraigh teorainn comharthaí
POST /api/usage/token-limits
Content-Type: application/json

{
  "apiKeyId": "key-123",
  "scopeType": "model",
  "scopeValue": "openai/gpt-4o",
  "tokenLimit": 1000000,
  "resetInterval": "monthly",
  "enabled": true
}

# Scrios teorainn comharthaí de réir a haitheantais
DELETE /api/usage/token-limits?id=tl-abc
```

> **Nótaí scéime** (`setTokenLimitSchema`): Tá `apiKeyId` agus `scopeType` (`model` | `provider` | `global`) riachtanach. Tá `scopeValue` riachtanach mura bhfuil `scopeType` socraithe mar `global` (m.sh. aitheantas samhla do scóip `model`, aitheantas soláthraí do scóip `provider`). Ní mór do `tokenLimit` a bheith ina shlánuimhir dheimhneach (arna comhshó ó theaghrán). Roghnach: `id` (fág ar lár é chun ceann a chruthú, soláthair é chun ceann a nuashonrú), `resetInterval` (`daily` | `weekly` | `monthly`, réamhshocrú `monthly`), `resetTime` (`HH:MM`), `enabled` (réamhshocrú `true`). Saibhríonn freagraí `GET` gach teorainn le `tokensUsed`, `remaining`, `windowStart`, `periodStartAt`, agus `nextResetAt`. Is críochphointe den aicme bainistíochta é seo (cuireann píblíne authz an fíordheimhniú i bhfeidhm go lárnach).

## Próiseáil Iarratas

1. Seolann an cliant iarratas chuig `/v1/*`
2. Glaonn láimhseálaí an bhealaigh ar `handleChat`, `handleEmbedding`, `handleAudioTranscription`, nó `handleImageGeneration`
3. Réitítear an tsamhail (soláthraí/samhail dhíreach nó ailias/teaglaim)

10. Cuirtear cúltaca i bhfeidhm i gcás earráidí de réir rialacha na teaglaime

## Athléimneacht (leathnaithe)

Cuireann OmniRoute trí shásra neamhspleácha teipe sealadaí ar fáil; ligeann na críochphointí bainistíochta thíos d’oibreoirí iad a léamh agus a shárú:

| Raon                | Stóráil staide                                 | Léamh                                     | Athshocrú / glanadh                                      |
| ------------------- | ---------------------------------------------- | ----------------------------------------- | -------------------------------------------------------- |
| Scoradán soláthraí  | `domain_circuit_breakers` + sa chuimhne        | `/api/monitoring/health`                  | `POST /api/resilience/reset`                             |
| Maolú naisc         | `rateLimitedUntil` ar naisc soláthraithe       | `/api/rate-limits`, `/api/providers/[id]` | (athchumasaítear go leisciúil é; glan trí PUT soláthraí) |
| Frithdhúnadh samhla | Clárlann infhaighteachta samhlacha sa chuimhne | `GET /api/resilience/model-cooldowns`     | `DELETE /api/resilience/model-cooldowns`                 |

Glacann `PATCH /api/resilience` le sáruithe ar scoradáin soláthraithe faoi `providerBreaker.oauth` agus `providerBreaker.apikey`. Tacaíonn gach próifíl le `degradationThreshold`, `failureThreshold`, agus `resetTimeoutMs`; tá na réimsí céanna ar fáil in Deais → Socruithe → Athléimneacht.

```bash
# Glan frithdhúnadh samhla amháin
curl -X DELETE http://localhost:20128/api/resilience/model-cooldowns \
  -H "Cookie: auth_token=..." \
  -H "Content-Type: application/json" \
  -d '{"provider":"openai","model":"gpt-4o-mini"}'

# Glan gach frithdhúnadh
curl -X DELETE http://localhost:20128/api/resilience/model-cooldowns \
  -H "Cookie: auth_token=..." \
  -d '{"all":true}'
```

Le haghaidh tagairt choincheapúil iomlán agus réamhshocruithe scoradáin: féach [`CLAUDE.md`](../../CLAUDE.md) → "Staid Ama Rite na hAthléimneachta" agus [`docs/architecture/RESILIENCE_GUIDE.md`](../architecture/RESILIENCE_GUIDE.md).

### Scuaine Teorannaithe Ráta & Líontán Sábhála Uathchumasaithe

- **Conair scríofa a dtacaítear léi**: Is é `POST /api/rate-limits` leis an gcorp `{"connectionId": "<id>", "enabled": true|false}` an críochphointe bainistíochta a dtacaítear leis chun cosaint teorannaithe ráta do nasc a scoránú. Ní mhodhnaíonn ná ní scoránaíonn `PUT /api/providers/[id]` `rateLimitProtection` d’aon ghnó (#11278).
- **Séimeantaic `enabled: false`**: Má shocraítear `enabled: false`, baintear cosaint shainráite den nasc, ach **ní** dhíroghnaítear nasc gníomhach eochair API ón líontán sábhála uathchumasaithe domhanda (`autoEnableApiKeyProviders = true`). In `reconcileEnabledConnections` (`open-sse/services/rateLimitManager.ts`), tá `false` agus `undefined` coibhéiseach; fanann naisc ghníomhacha eochair API gan chosaint shainráite faoi chosaint an líontáin sábhála uathchumasaithe.
- **Díchumasú domhanda**: Chun naisc eochair API a rith gan scuainí teorannaithe ráta, díchumasaigh an líontán sábhála go domhanda trí `RATE_LIMIT_AUTO_ENABLE=false` (athróg timpeallachta) nó `resilienceSettings.requestQueue.autoEnableApiKeyProviders = false` (Socruithe → Athléimneacht / `PATCH /api/resilience`).

## Freastalaí MCP

Tagann OmniRoute le freastalaí leabaithe Model Context Protocol ina bhfuil 3 iompar (stdio, SSE, streamable-http) agus uirlisí de réir raoin feidhme. Léann críochphointí an deais thíos sonraí stádais/iniúchta agus déanann siad seachfhreastalaíocht ar na hiompair HTTP.

| ------ | ---------------------- | ------------------------------------------------------------------------------------------------ | -------------------- |

| GET | `/api/mcp/stream` | Oscail taobh SSE den iompar Streamable HTTP (teachtaireachtaí arna dtionscnamh ag an bhfreastalaí) |

## Freastalaí A2A

Nochtann OmniRoute críochphointe A2A (Gníomhaire le Gníomhaire) JSON-RPC 2.0 chomh maith le fillteán REST le haghaidh iniúchta agus úsáide deaise.

### JSON-RPC

```bash
POST /a2a
Authorization: Bearer your-api-key   # roghnach mura bhfuil OMNIROUTE_API_KEY socraithe
Content-Type: application/json

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "message/send",
  "params": {
    "skill": "smart-routing",
    "messages": [{"role": "user", "content": "Route this coding task"}]
  }
}
```

Modhanna a dtacaítear leo (iad uile ag brath ar `settings.a2aEnabled`):

| Modh             | Cur síos                                                            |
| ---------------- | ------------------------------------------------------------------- |
| `message/send`   | Rith sioncrónach scile; tugtar `{task, artifacts, metadata}` ar ais |
| `message/stream` | Rith sruthaithe SSE den tacar céanna scileanna                      |
| `tasks/get`      | Faigh tasc de réir `taskId`                                         |
| `tasks/cancel`   | Cealaigh tasc de réir `taskId`                                      |

Scileanna ionsuite: `smart-routing`, `quota-management`, `provider-discovery`, `cost-analysis`, `health-report`.

### Cárta Gníomhaire

```bash
GET /.well-known/agent.json
```

Tugtar cárta poiblí gníomhaire A2A ar ais (ainm, cur síos, cumais, catalóg scileanna, scéim fíordheimhnithe) — déantar é a thaisceadh go poiblí ar feadh 1u. Ní theastaíonn fíordheimhniú.

### Cúntóirí REST

| Modh | Conair                       | Cur síos                                                                                                                |
| ---- | ---------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| GET  | `/api/a2a/status`            | A2A cumasaithe + staitisticí tascanna + achoimre thaiscthe ar chárta an ghníomhaire                                     |
| GET  | `/api/a2a/tasks`             | Liostaigh tascanna — `?state=submitted\|working\|completed\|failed\|cancelled`, `?skill=`, `?limit=` (≤200), `?offset=` |
| POST | `/api/a2a/tasks`             | (Níl sé curtha i bhfeidhm mar chúntóir REST — cruthaigh trí JSON-RPC `message/send`)                                    |
| GET  | `/api/a2a/tasks/[id]`        | Aisghabh tasc amháin                                                                                                    |
| POST | `/api/a2a/tasks/[id]/cancel` | Cealaigh tasc                                                                                                           |

**Fíordheimhniú:** ritheann na cúntóirí REST gan fíordheimhniú bainistíochta (inléite ag an deais); úsáideann bealach JSON-RPC `/a2a` Bearer `OMNIROUTE_API_KEY` má tá sé cumraithe.

## Fíordheimhniú

Féach [Fíordheimhniú Bainistíochta](../guides/MANAGEMENT-AUTH.md) chun eolas a fháil ar na ceithre
theaghlach dintiúr (seisiún painéil, comhartha CLI áitiúil, Comhartha Rochtana `oma_live_…`,
eochair API le raon feidhme bainistíochta) agus ar an difríocht atá eatarthu agus eochracha tátail.

- Úsáideann bealaí an phainéil (`/dashboard/*`) fianán `auth_token`
- Úsáideann an logáil isteach hais sábháilte an fhocail faire; úsáidtear `INITIAL_PASSWORD` mar chúltaca
- Is féidir `requireLogin` a scoránú trí `/api/settings/require-login`
- Féadfaidh eochair API Bearer a bheith riachtanach do bhealaí `/v1/*` nuair atá `REQUIRE_API_KEY=true`
- Ciallaíonn “comhartha bainistíochta” / “eochair API le raon feidhme bainistíochta” sa tagairt seo ceann de na teaghlaigh sa treoir sin — ní cineál rúin bhreise neamhshainithe

> **Athrú neamh-chomhoiriúnach (v3.8.0)** — teastaíonn **fíordheimhniú bainistíochta** anois ó `/api/v1/agents/tasks/*` agus ó na críochphointí bainistíochta tréimhse shuaimhnis (fianán `auth_token` an phainéil nó eochair API le raon feidhme bainistíochta). Gheobhaidh cliaint a ghlaoigh ar na bealaí seo roimhe seo gan fíordheimhniú `401 Unauthorized`. Féach tiomantas `588a0333` (`fix(auth): require management auth for agent and cooldown APIs`).
