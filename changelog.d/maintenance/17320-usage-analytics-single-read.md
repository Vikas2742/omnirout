- **perf(usage-analytics):** the analytics endpoint reads the unified cost source once and rolls every panel up in memory. `getDailyCostRows`, `getModelUsageRows`, `getProviderCostRows`, `getProviderUsageRows` and `getServiceTierUsageRows` each ran their own `GROUP BY` over the same UNION of `usage_history` and `daily_usage_summary`, so one dashboard load made five passes plus five temp B-tree sorts. They are replaced by a single `getModelUsageMatrixRows` read on `(date, provider, model, serviceTier)` and the `derive*Rows` roll-ups, which are exact: every measure is additive and the latency average is recombined from the carried `latencyWeightedMs` / `latencySamples` pair. A new panel now costs no extra SQL pass.
