- **fix(sse):** the flush-empty retry loop (`FLUSH_EMPTY_RETRY_ENABLED`, opt-in) now also covers direct, non-translated turns, and a turn whose whole output is draft/system-echo markup (`<summary>`, `<analysis>`, `<system-reminder>`) counts as an empty turn instead of a normal one. The loop used to be armed for translated streams only, so a direct openai→openai turn never reached it, and the draft skeleton a model emits instead of an answer was classified as usable content — the client stripped the tags, was left with an empty turn and killed the stream. The recovery stays opt-in and bounded: the turn is retried on another connection within the existing retry budget, and a turn the judge cannot summarize still passes through unchanged.
